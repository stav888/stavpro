# Copilot Bot: Midjourney Animation Producer

> **בעברית בקצרה:** תיקייה זו מרכזת את הנחיות ההפעלה והתהליכים הייעודיים ל-**Copilot** (הסוכן / AI Assistant ב-VS Code) לצורך ביצוע משימות הנפשת תמונות סטילס (Image-to-Video) ב-Midjourney באופן אוטונומי, מדויק ורציף.

---

## תפקיד הסוכן (Agent Role)

| בוט / סוכן | סביבה | תפקיד עיקרי | מסמך מנחה |
|---|---|---|---|
| **Copilot Midjourney Producer** | VS Code Integrated Browser (`openBrowserPage`) | ניסוח פרומפט הנפשה, העלאת תמונת סטילס ל-Midjourney, שליחת ג'וב וידאו, הפעלת תצוגה מקדימה סימולטנית (Hover), בקרת איכות (QA) וסימון לייק רק אחרי אישור המשתמש לאותו קליפ. | [`copilot-midjourney-producer.md`](copilot-midjourney-producer.md) |
| **Copilot Midjourney QA** | VS Code Integrated Browser (`screenshotPage`, `hoverElement`) | בודק לפני ואחרי כל הרצה: מצב Video, Start/End Frame, Loop, מצלמה נעולה (אי-zoom), זיהוי הג'וב הנכון, ולייק רק אחרי אישור לאותו קליפ. מדווח PASS/FAIL בעברית ולא שולח ג'ובים בעצמו. | [`copilot-midjourney-qa.md`](copilot-midjourney-qa.md) |

## 2. חוקי ברזל תפעוליים עבור Copilot

1. **עבודה אך ורק דרך הדפדפן הפנימי של VS Code:**
   - **אין לפתוח דפדפן כרום חיצוני נפרד** ללא שיתוף כלים.
   - יש להשתמש בדפדפן המובנה של VS Code באמצעות כלי הדפדפן (`openBrowserPage`, `clickElement`, `typeInPage`, `hoverElement`, `screenshotPage`).
   - בכך נשמר סשן ההתחברות הפעיל של המשתמש ב-Midjourney ללא ניתוקים.
2. **ברירת מחדל: תמונת פתיח בלבד (Start Frame Only):**
   - אין להגדיר תמונת סיום (`End Frame`) אלא אם המשתמש דרש זאת באופן מפורש.
   - בתמונה בודדת — יש להציע למשתמש בחירה ברורה: האם לבצע פתיח בלבד, או לשלב פתיח וסיום.
3. **ניסוח פרומפטים מבוססי מיקרו-תנועות:**
   - לעולם אין לבקש תנועות גוף רחבות או פעולות דרמטיות על תמונת סטילס (זה גורם לעיוותי איברים וגליצ'ים).
   - יש להשתמש בנוסחת המיקרו-תנועות: מצמוץ עדין, תנועת אוזניים/זנב, נשימה קלה, רוח בעלים, השתקפויות אור, עיגון עצמים נייחים (`remains completely still`), ומצלמה נעולה (`locked-off camera`). אין `push-in`, `zoom`, `dolly` או `move closer`.
4. **טכניקת הריחוף להשוואת 4 הווריאציות:**
   - לאחר סיום הפקת הג'וב, Copilot ימקם את סמן העכבר באמצעות `hoverElement` ישירות מתחת לשורת הפרומפט כדי שכל 4 הסרטונים יתנגנו בו-זמנית.
5. **בקרת איכות (QA) אוטונומית:**
   - בדיקת עיוותים, איברים שנעלמים, קפיצות פריימים ויציבות מצלמה.
   - בחירת הווריאציה החלקה והטבעית ביותר.
6. **לייק רק אחרי אישור מפורש לאותו קליפ:**
   - אחרי שהמשתמש אישר את הווריאציה הספציפית, סימון כפתור הלב (`Like video (L)`) ישירות באריח, ללא צורך בפתיחת הסרטון, ואימות שהכפתור הפך ל-`Unlike video (L)`.
7. **פירוק תסריט לסצנות מונפשות:**
   - כאשר המשתמש מספק תסריט שלם, יש לפרק אותו לחלקים ולהציע פרומפט הנפשה ייעודי עבור כל חלק בתסריט.
8. **יצירת תמונות סטילס אך ורק עם GPT כברירת מחדל:**
   - כאשר המשתמש מבקש להכין / ליצור תמונה, יש להשתמש אך ורק בכלי ה-GPT המובנה (`image_generation`), אלא אם התבקש אחרת במפורש.
