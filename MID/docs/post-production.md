# הורדה, שמירה ואיחוד קליפים אחרי Midjourney (Post-Production)

> Midjourney מפיק קליפים נפרדים לכל ג'וב (פתיח, Extend וכן הלאה). **הוא אינו מאחד** קטעים לתסריט אחד. האיחוד לרצף וידאו נעשה כאן, מחוץ לממשק Midjourney, רק אחרי שהמשתמש אישר במפורש כל קליפ.

---

## 1. הורדת הקליפ שאושר

בממשק Midjourney (לחיצה ימנית על הסרטון בעמוד Create או Organize) יש שלוש אפשרויות הורדה:

| אפשרות | מתי להשתמש | פורמט |
|---|---|---|
| **Download Raw Video** | עריכה ואיחוד מקומי (ברירת המחדל כאן) | `.mp4` |
| **Download for Social** | שיתוף ישיר ברשתות, בלי עריכה נוספת | `.mp4` (קידוד מותאם לרשתות) |
| **Download Gif** | תצוגה מקדימה קצרה בלבד, לא לסרטון סופי | `.gif` |

מ-Discord מורידים את קובץ ה-Raw. אחרי ההורדה שומרים לפי מוסכמת השמות למטה.

---

## 2. תיקיית פלט (מחוץ ל-git)

שומרים את כל קובצי הווידאו בתיקייה מקומית שאינה נכנסת לריפו:

- **מומלץ:** `MID/output/` — התיקייה מופיעה ב-[`.gitignore`](../.gitignore) יחד עם `*.mp4`, `*.webm`, `*.mov`.
- לחלופין אפשר לשמור מחוץ לריפו לגמרי (למשל בתיקייה מקומית אחרת במחשב).

אין להעלות ל-git קובצי וידאו או טיוטות עריכה.

---

## 3. מוסכמת שמות

```text
scene-<NN>_<stage>_v<N>.mp4
```

| חלק | משמעות | דוגמה |
|---|---|---|
| `scene-<NN>` | מספר הסצנה בתסריט, בשתי ספרות | `scene-01` |
| `<stage>` | `start` (קליפ הפתיח) או `extend` (המשך) | `start` |
| `v<N>` | מספר הווריאציה שאושרה בגריד (1–4) | `v3` |

דוגמאות:

```text
output/scene-01_start_v3.mp4
output/scene-01_extend_v2.mp4
output/scene-02_start_v1.mp4
```

סרטון מאוחד סופי: `output/film-<שם-קצר>.mp4` (למשל `output/film-cat-beside-car.mp4`).

---

## 4. איחוד הקליפים שאושרו (ffmpeg concat)

רק קליפים שהמשתמש אישר במפורש נכנסים לאיחוד, לפי סדר התסריט (פתיח ואחריו Extend של אותה סצנה, ואז הסצנה הבאה).

יוצרים קובץ רשימה, למשל `output/concat-list.txt`:

```text
file 'scene-01_start_v3.mp4'
file 'scene-01_extend_v2.mp4'
file 'scene-02_start_v1.mp4'
```

הנתיבים הם יחסיים למיקום קובץ הרשימה. מתוך `MID/output/` מריצים:

```bash
ffmpeg -f concat -safe 0 -i concat-list.txt -c copy film-cat-beside-car.mp4
```

`-c copy` מאחד בלי המרה מחדש, ומתאים כשכל הקליפים באותו קידוד, יחס ממדים וקצב פריימים. אם האיחוד נכשל או שיש קפיצה בתפר, מאחדים עם המרה מחדש:

```bash
ffmpeg -f concat -safe 0 -i concat-list.txt -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac film-cat-beside-car.mp4
```

אם לקליפים אין פס שמע, אפשר להשמיט את `-c:a aac`.

---

## 5. מה לא לצפות מ-Midjourney

- Midjourney לא מחבר סצנות ולא מייצא תסריט שלם.
- לייק בחשבון רק מסמן מועדף להורדה; הוא אינו יוצר קובץ מאוחד.
- כל Extend הוא קליפ המשך נפרד, שמצרפים ידנית לקליפ הפתיח לפי הצעדים למעלה.
