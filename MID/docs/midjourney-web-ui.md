# מדריך עבודה בממשק Midjourney Web (UI Walkthrough)

> מדריך טכני מפורט לעבודה עם אתר Midjourney במצב וידאו / הנפשה (Animate), כולל דגשי סביבת עבודה והגדרות מדויקות.

---

## 1. סביבת עבודה והגדרת הדפדפן

- **העדפת סביבה ברורה:** עבודה ישירות דרך **הדפדפן הפנימי המובנה של VS Code** (ולא דרך דפדפן כרום חיצוני עצמאי).
- **יתרונות:**
  - שמירה רציפה על חיבור ה-Session של המשתמש.
  - מניעת ניתוקי התחברות וחלונות רקע לא מנוהלים.
  - יכולת שליטה, צפייה, ריחוף עכבר (Hover) ולחיצה מתוך סביבת הפיתוח.
- **כתובת הממשק:** `https://www.midjourney.com/imagine`

---

## 2. שלבי העלאה והפעלת מצב וידאו (שלב אחר שלב)

### שלב א': פתיחת שורת הפקודות (Imagine Bar)
1. ניווט לדף `https://www.midjourney.com/imagine`.
2. ודא שאתה מחובר לחשבון (או שהסשן שמור).
3. בתחתית/מרכז הדף נמצאת שורת הפקודה `Imagine...`.

### שלב ב': העלאת תמונת המקור (Add Images)
1. לחץ על כפתור הוספת תמונות:
   - כפתור `Add images` (אלמנט `button[aria-label="Add images"]` או סמל הפלוס/תמונה).
2. בתפריט שנפתח, בחר באפשרות:
   - `Upload a file or drop it here`.
3. בחר בקובץ התמונה המקומי (לדוגמה קובץ בפורמט PNG/JPG ביחס `9:16`).
4. התמונה תופיע כפריט מצורף מעל שורת ההקלדה.

### שלב ג': מעבר למצב וידאו (Switch to Video / Animate)
1. לחץ על לחצן המעבר להנפשה / וידאו:
   - לחצן `Switch to video` או אייקון מצלמת הווידאו שליד שורת הפרומפט.
2. הממשק יעבור למצב יצירת וידאו, ותראה חיווי שהתמונה משמשת כ-Source Frame להנפשה.

### שלב ד': הזנת פרומפט ההנפשה
1. הדבק את פרומפט ההנפשה הייעודי (לפי תבנית המיקרו-תנועות והמצלמה).
2. Midjourney יצרף אוטומטית את פרמטרי הווידאו:
   - משך ברירת מחדל: `--duration 5.2s`.
   - יחס ממדים תואם למקור (למשל `--ar 171:256` עבור תמונת 9:16).
3. לחץ `Enter` לשליחת המשימה.

---

## 3. מעקב אחר יצירת הווידאו

- המשימה נכנסת לתור היצירה ומקבלת Job ID ייחודי (לדוגמה `023be633-f955-4da2-97e2-5a1dc9a3de56`).
- תוך מספר רגעים נוצרת גריד של **4 וריאציות וידאו שונות** על בסיס אותה תמונת מקור ואותו פרומפט.
- כל וריאציה מדגימה תנועתיות קצת שונה (קצב נשימה, זווית התקרבות, תנועת רקע).

---

## 4. מקשי קיצור ופעולות ממשק שימושיות

| פעולה | אלמנט בממשק | קיצור מקלדת |
|---|---|:---:|
| הוספת תמונה | `button[aria-label="Add images"]` | – |
| לייק / מועדף לווידאו | אייקון הלב בפינה הימנית העליונה של האריח | `L` |
| ביטול לייק | לחיצה חוזרת על הלב (`Unlike video`) | `L` |
| הפעלת תצוגה מקדימה לכל ה-4 | הצבת סמן העכבר מתחת לטקסט הפרומפט | Hover |
