# YT1

תיקיית התוכן של ערוץ הילדים. כל תמונה או סרטון שמבוקשים נשמרים כאן.

## הדמות

- **סוג:** ילדה חמודה בסגנון צ'יבי תלת-ממדי (אנימציה בסגנון Pixar)
- **שיער:** כחול, קצר, בסגנון בוב
- **אביזר חתימה:** קליפס כוכב צהוב בשיער
- **לבוש:** ז'קט לבן עם הוד, מכנסיים שחורים, נעלי ספורט לבנות
- **תיק:** תרמיל אדום
- **אביזר עלילתי:** קופסת זהב זוהרת עם כוכבים (אוצר)
- **אופי:** הרפתקנית צעירה, סקרנית, אופטימית ואמיצה. תמיד מחפשת את ההרפתקה הבאה.

קובץ הרפרנס: [character-reference-sheet.png](./character-reference-sheet.png)

## סוג הערוץ

ערוץ הרפתקאות לילדים עם דמות קבועה. כל פרק הוא מסע קצר לגילוי אוצר או רמז, עם עלילה פשוטה, אווירה שמחה וערכים חיוביים כמו אומץ, סקרנות וחברות.

## מה הערוץ מציע

- סיפורי הרפתקאות קצרים עם תחושת חיפוש ותגלית
- קומיקס בפאנלים עם דיאלוגים קצרים וקריאים
- סרטונים קצרים עם הדמות ועולמה
- תוכן מתאים לגילאי ילדים, עם צבעים בהירים ותחושה חמה

## מה נכין בהמשך

- [ ] קומיקס ההרפתקה הראשון (הכנה לפי הפאנלים בתמונת ההשראה)
- [ ] עולמות ומיקומים קבועים (עיר חוף עם עמודי שיש וכפרים צבעוניים)
- [ ] סרטוני פתיחה וסיום קבועים לערוץ
- [ ] דמויות משנה ורפרנסים נוספים
- [ ] כותרות, תמונות ממוזערות ותיאורים לסרטונים

## הערות

- הפרטים בקובץ זה כלליים ויתעדכנו לפי ההחלטות שלך.
